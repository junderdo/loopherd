# D14

## Decision

Slice 5 is `loopherd feed <herd> [--dry-run]`, a one-shot idempotent run (no
daemon) under an exclusive non-blocking `flock` on
`$XDG_STATE_HOME/loopherd/feed.lock`. Each task gets a **fresh member**
spawned through `add`'s code path, not an idle member re-prompted. A herd
file's `[queue]` names one `template`, a `source` shell command and `max ≥ 1`;
every non-retired member of the herd, gone or `done` included, holds a slot.
`source` runs as `sh -c` in `repo` and prints one task per line,
whitespace-split into the template's params; order is priority, blank and `#`
lines ignored, a bad line is an error for that line only, and a run whose only
errors are bad lines exits 4 (LH-53). A task whose rendered member name is
already in the ledger, retired or not, is skipped forever; reviving work means
a new task. **Reap** runs first: a template's optional `done` command (same
placeholders, each value shell-quoted since params come from the source's
output; `sh -c` in `repo`; process-group timeout, and the group is killed once
the check exits) runs for each non-retired member with recorded `params`; exit
0 runs `retire --close` under all its rules, exit 1 means open, anything else
is open with a warning. Stop rules: a failing source or unreachable herdr
spawns nothing and exits non-zero; a spawn that fails or comes up `blocked`
ends the run after that task (D10). The ledger gains `params`. `--dry-run`
runs `source` and `done` but neither spawns nor retires. loopherd stays free
of Trello and GitHub knowledge: the herd file's commands carry it. A manual
`add` into a herd with a `[queue]` takes the same lock, refusing while a feed
runs, and still adds past `max` with a warning, since it is the human's
override (LH-54). Built as LH-49 (fill) then LH-50 (reap).

## Why

The first loop to automate is the card loop the shepherd runs by hand: pick a
claimable card, spawn its agent, retire after merge. Counting open work, not
running processes, bounds the human's review load. Grilled with the human
2026-11-01.
