# D162

## Decision

Amends D91. `[shepherd] self_restart` defaults to true: with no key in
`config.toml`, `loopherd restart --self` from the shepherd arms the waiter.
`self_restart = false` turns it off, refusing `restart --self` and stopping a
pending waiter as D91's switch-off does. `config get shepherd.self_restart`
still reports an unset key as unset.

- **Doctor.** The warning that the UserPromptSubmit hook is missing fires
  whenever self-restart is on, set or by default. The warning that
  `[notify]` doesn't send `self_restart` fires only for an explicit
  `self_restart = true`, so a default install without `[notify]` sees no
  new warning; a give-up still labels the pane.
- **Unchanged:** D91's times (the 5-minute window, the 30-minute give-up and
  guard), restarts for leads and members, and `[notify]`'s default.

## Why

D91 made the switch opt-in because a `/clear` the human didn't type wipes
the screen they read the shepherd on. D91's safeguards answer that: the
restart waits for 5 minutes with no prompt in the pane and an empty input
box, any prompt cancels it, and a give-up falls back to the manual resume
with a pane label. The human decided on 2026-11-24 that it should default
to on (LH-570).
