# D7

## Decision

Herd files live only in `$XDG_CONFIG_HOME/loopherd/herds/<herd>.toml` (default
`~/.config/loopherd/herds/`), one file per herd, named by its filename.
`LOOPHERD_CONFIG_DIR` overrides the directory for tests and dev. No repo-local
lookup, no merging. Versioning them (e.g. in dotfiles) is the user's business.

## Why

They're personal config spanning repos (D6). Committing them to a work repo
would be noise for teammates. Grilled in LH-5.
