# D11

## Decision

The ledger is a JSON file at `$XDG_STATE_HOME/loopherd/ledger.json`, written
by temp file + rename. Lost updates from concurrent writers were a known gap,
closed by `ledger.lock` in LH-70 (D16). Revisit SQLite only if the queue slice
needs many concurrent writers.

## Why

A few loopherd processes on one machine (D6). The file is easy to inspect.
LH-8, [ADR 0001](../adr/0001-json-file-ledger.md).
