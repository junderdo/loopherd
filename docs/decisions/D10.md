# D10

## Decision

loopherd never answers `blocked` agents: spawn, revive, prompt and add only
report them. Revisit with a per-dialog allowlist only if a real loop keeps
stalling on the same dialog.

## Why

The only routine blocker, the trust dialog, has a setup fix (LH-15). Answering
on the human's behalf is the riskiest thing loopherd could do. Grilled in
LH-7.
