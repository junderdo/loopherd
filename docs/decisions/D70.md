# D70

## Decision

How many review rounds a lead runs on a PR before asking the human is
`review_rounds`, a positive integer that resolves as a lead's switches do
(D31): the herd file's `[lead]`, else `[lead_defaults]` in
`$LOOPHERD_CONFIG_DIR/config.toml`, else 3. Zero, a negative number or a
non-integer makes the file invalid, as `loopherd herds` reports.

The lead's prompt gets the resolved value as `{review_rounds}`, which
`loopherd init`'s built-in lead prompt uses; `loopherd lead` appends
`Your review-round limit: <n>.` to a prompt that doesn't use the
placeholder, so prompts written before it still carry the limit. The skill's Lead section points
at "your herd's review-round limit (in your prompt; 3 when unset)" instead of
naming 3. `loopherd herds` shows each led herd's value with its source
(`herd file`, `lead_defaults` or `built-in`), or `unknown until config.toml
is fixed` while `config.toml` is invalid, since `loopherd lead` then refuses.

`loopherd herd set <herd> lead.review_rounds <n>` sets the herd's value and
`loopherd config set lead_defaults.review_rounds <n>` the default.
`loopherd lead-defaults --set` writes only the six switches, so it keeps an
existing `review_rounds`, and its printed lines stay the six switches. The
tool hook denies both writes in a lead's pane, as it does every `herd set`
(D29) and `config set` (D39).

A `[lead_defaults]` that sets `review_rounds` and no switch counts as no
lead defaults for `loopherd setup`, which still asks for the switches, and
for `loopherd lead-defaults`, which prints nothing.

This amends D31: `[lead_defaults]` takes the six switch names, each a
boolean, and `review_rounds`, a positive integer; any other key makes
`config.toml` invalid.

## Why

The limit was a number fixed in the skill text (LH-157), so changing it
meant overriding the skill in prose in a lead's prompt (LH-193 ran 5 rounds
that way) or editing the skill and releasing. Resolving it like the switches
reuses a layering the human already knows, and `{review_rounds}` in the
prompt keeps the skill text true for every herd. A separate placeholder,
rather than a line in `{switches}`, keeps `{switches}` the on/off list the
tool hook and `feed` enforce. Decided on LH-254.
