# D167

## Decision

`loopherd init` offers a `wayfinding` template and routes the queue to it
(LH-557), the second of D158's templates. Applies D25 to init's own herds.

- **Asked like groom.** After the groom question, on a terminal: `Add a
  wayfinding template, for research, domain and prototype tasks?`, default
  yes, with a two-line explanation above it. Off a terminal only
  `--with wayfinding` writes it. The summary shows `wayfinding yes` or `no`.
- **Routed queue.** With it, `[queue]` has `templates = ["issue",
  "wayfinding"]` and `source` prints the template name first on each line.
  A task with `wayfinding:research`, `wayfinding:domain` or
  `wayfinding:prototype` goes to `wayfinding` as type `docs` with the
  `research`, `domain-modeling` or `prototype` skill; any other goes to
  `issue`. GitHub reads labels, a local tracker the same words on the
  `Status:` line, and another tracker gets a comment naming the rule
  beside its empty `source`. `backlog` is unchanged.
- **Without it, nothing changes**: `template = "issue"` and the unprefixed
  source, byte for byte as before (a golden test holds this).
- **The template is the issue template's settings**, rendered from it:
  same `params`, `context_limit`, `done` and `merged`, with `name`
  `{herd}-research-{number}` (local `{id}`), branch `docs/{number}-{slug}`
  (local `{id}`), and no `args`. Its prompt per tracker claims the task,
  resolves it with `{skill}`, commits the output on the branch, hands it in
  closing the task with a three-line summary, and stops on a question as
  the issue prompt does. It runs no checks: its output is docs or a
  throwaway prototype.
- **Labels and docs.** GitHub creates the three labels where missing, as
  it does the triage labels. The tracker doc and `docs/agents/loopherd.md`
  init writes get a `## Wayfinding tasks` section, only with wayfinding.
- **Research names fit 32 characters.** `-research` makes the name 9
  characters longer. A local source cuts a wayfinding issue's id 9 shorter
  (hashing it as it does a long feature), and skips the issue, saying why,
  only when the herd name leaves no room. For GitHub and other trackers
  init needs a herd name of at most 16 characters, so a 6-digit number
  fits: `--with wayfinding` is refused past that, and a terminal isn't
  asked. Otherwise feed would stop on the first too-long name every run.
- **Tracker docs tell the labels apart** from `/wayfinder`'s
  `wayfinder:` labels (local: `Type:` lines), which loopherd doesn't
  route.

The `wayfinding` migration D157 asks for waits on LH-563 and LH-497 and
is carried on LH-581.

## Why

loopherd-cards already runs research, domain and prototype cards on their
own template (D25), and a new herd should get the same split for one
keypress. Deriving the template from the rendered issue template keeps
its `done` and `merged` in step with the tracker's without a second copy.
