# D174

Amends D135.

## Decision

Follow-ups to the release installer's extras (LH-469):

- **Needs.** Only the skills plugin and the herdr offers need jq.
  `install-extras` checks for it, not `install.sh`: without jq the agent
  types are still offered, and the rest is skipped with one line naming
  jq. Supersedes D135's "the extras need bash and jq".
- **Already installed, read-only.** Agent types found byte-identical to
  loopherd's on a run that asked nothing (no terminal, or a terminal run
  that skips the question because they're installed) are not recorded in
  `agents.sha256`. Only a yes or `--with-agents` records them, so a copy
  the human made stays theirs under D26 until they say otherwise.
- **claude under a timeout.** Each read-only claude call (`plugin list`,
  `plugin marketplace list`) runs as `timeout -k 5 10` where `timeout`
  exists, with stdin from `/dev/null` (LH-613), and under `setsid` where
  it exists (LH-620). On a terminal, timeout's background group stops a
  claude touching it; uutils' timeout (Ubuntu 25.10 on) never KILLs a
  stopped child, so `setsid` leaves claude no terminal to stop on. No
  `--foreground`, which BusyBox's timeout lacks.
- **The release's herdr plugin.** `install.sh` passes the installed tag
  to the extras as `LOOPHERD_EXTRAS_RELEASE`. A fresh plugin install then
  runs `herdr plugin install junderdo/loopherd/herdr-plugin --ref <tag>`
  when `herdr plugin install --help` names `--ref`; otherwise it installs
  GitHub's default branch and says so. Messages say "this release" rather
  than "this checkout", and the by-hand reinstall names the ref. An update
  of an installed plugin still runs `herdr plugin update`, which follows
  the ref it was installed from. `scripts/install` passes no tag: a
  checkout's plugin comes from the default branch, as before.

## Why

LH-463's review found each as a gap against what D135 and D26 say. A
host without jq got none of the agent types, which never read jq. D135
calls the no-terminal extra work read-only, yet the agent offer wrote the
ledger, turning the human's own copies into loopherd's without a
question. D126 already guarded herdr's list call against a wedged server;
claude's had no such guard. A release binary behind main could get a
herdr plugin from main whose actions call subcommands it lacks.
