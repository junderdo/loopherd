# D36

## Decision

`loopherd init` takes the tracker from the repo's
`docs/agents/issue-tracker.md` (D35 items 6 to 9), as built in LH-124:

- A doc whose first `# ` heading (after any byte-order mark or text above
  it) is `Issue tracker: GitHub`, in any case, gets the built-in GitHub
  snippets (local markdown gets its own, D38). Any other doc
  gets `source = ""` under a comment saying to fill it from
  the doc; `loopherd herds` reports a blank queue `source` invalid, so feed
  refuses the herd. init creates no labels for a non-GitHub tracker, and a
  placeholder herd still names its repo, so init in another repo reads past
  it.
- `triage-labels.md` is read as mattpocock's table: a row whose first cell is
  `ready-for-agent`, `needs-info` or `ready-for-human` (any case) maps it to
  the second cell. Those names go into the queue's `--label` filter, its
  exclusions, the worker's question label and the labels init creates;
  `blocked` stays loopherd's. A label naming `blocked`, or two roles sharing
  one label, is refused before any gh call. For GitHub, whose snippets put
  labels in shell commands unquoted, so is a label outside letters, digits
  and `- _ . : /` or starting with `-`.
- With no tracker doc, init takes `--tracker github|local|other`; without
  it, it asks on a terminal (stdin and stderr both terminals), re-asking an
  unknown answer and taking an empty one as `github`, and unattended it
  defaults to `github`. `other` takes its prose from `--tracker-desc`, else
  asks for it on a terminal until it's non-empty, else is refused. init
  writes `issue-tracker.md` and, when absent, `triage-labels.md` with the
  defaults, uncommitted, after the herd files. A failed doc write removes
  the files init wrote; the GitHub labels it created and any `docs/agents/`
  directory it made stay. `--tracker` beside an existing doc is refused.

## Why

The doc is mattpocock-skills' convention, so a repo set up by either tool
reads the same way. Recognising only GitHub's title keeps the snippets from
running against a tracker they don't fit; an empty `source` is a placeholder
the existing validation can catch without a sentinel string.
