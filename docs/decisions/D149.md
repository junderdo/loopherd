# D149

## Decision

A sandboxed worker in a `credentials` herd is refused, under `require` and
`prefer` alike, for anything that loosens its sandbox (LH-427, the human's
call on 2026-11-22). Amends D107's LH-341 credentials bullet and D128.

- **Settings and args.** D100's settings checks (the human's
  `~/.claude/settings.json` and the worktree's project and local settings)
  and LH-316's args allowlist refuse the worker as `NotStarted`, so a feed
  prints `not started` and goes on, naming each file and key or arg. The
  refusal reads `<name> can't start with merge_guard = "credentials": …` and
  names `[lead] merge_guard = "hook"`, with `[worker] sandbox = "prefer"`
  under `require`, as the fix. `revive` and `restart` refuse the same way.
  Non-credentials herds still only warn under `prefer`.
- **This closes the worker side of D100's credentials check.** A worker's
  settings already carry the herd's credentials `denyRead`, so an
  `allowRead` reaching `~/.config/gh` is a loosening, and now it refuses the
  worker as it refuses the credentials lead.
- **A broken `config.toml` doesn't stop a worker.** Whether a herd's workers
  are confined is read as `loopherd herds` reads it: `[lead_defaults]` that
  can't be read count as `merge` off, so a `credentials` herd stays confined
  and a `hook` herd's workers still start. Before this, `feed` stopped and
  `revive` failed on the parse error.
- **Doctor** already fails a `credentials` herd whose workers aren't
  `require` as invalid and skips its other checks, so these findings never
  show there as warnings. Only a hand-edited herd file reaches `feed` that
  way, since nothing but `herds`, `herd set` and doctor validates it.

## Why

- **The same exposure D107 already refused.** A loosened settings file or
  `--add-dir` can reopen reads of the herd's deploy key and token, which is
  what refusing an unsandboxed `prefer` worker guards against. The
  credentials lead (D95) refuses both under either mode; its workers match.
- **Tolerate, then confine.** Failing every worker start on a typo in
  `config.toml` blocked feeds that never needed the switches; counting
  `merge` off keeps the stricter reading rather than the looser one.
