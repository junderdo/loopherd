# D6

## Decision

loopherd covers work (zagops) and personal projects on one machine, and stays
a personal tool: teammates never consume herd definitions. Multi-machine
(`herdr --machine`) is out of v1; the `Herdr` trait must not rule it out. No
special guards for work repos: loopherd sends only prompts you wrote, under
the permission mode you chose.

## Why

Work PRs are the D3 pain, and they already run in the same herdr session.
Teammates don't run herdr. There's no second machine yet. Grilled in LH-4.
