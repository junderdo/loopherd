# D22

## Decision

`watch`'s lead lookup and `retire --close`'s check for a reused pane match a
non-retired ledger entry with D21's rule: pane id and herdr socket together,
a socketless entry matching only a caller without a socket. A watch whose
pane matches a lead on pane but not socket is the shepherd's watch, no longer
an error (narrowing D17), and warns once on start naming the lead, its
recorded socket and the watch's socket. `retire --close` compares against the socket of the
herdr it is closing in, so a live member with the same pane id in another
herdr no longer keeps the tab.

## Why

Pane ids repeat across herdr sessions (LH-97). D17's error stopped a
shepherd whose watch ran in herdr B on the same pane id as a lead in herdr A,
and the reuse check refused to close a tab for a member in another herdr.
Using D21's one rule at every pane match keeps them consistent; a lead whose
recorded socket doesn't match its watch's (a socketless pre-D21 entry, or a
revive where herdr named none) would otherwise take the shepherd's lock and
cursor silently, so the warning tells it to stop.
