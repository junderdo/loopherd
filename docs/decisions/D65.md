# D65

## Decision

The herdr plugin declares a `[[link_handlers]]` entry for
`^https://github\.com/[^/]+/[^/]+/pull/[0-9]+` that runs the `pr-member`
action, `sh loopherd.sh pr`. `loopherd pr` reads
`HERDR_PLUGIN_CLICKED_URL`, cuts it to the PR's own URL (dropping
`/files`, a query or a fragment) and looks for its owner among open
members, retired ones never counting:

1. The member whose current run (entries since its ledger `created`) has a
   report naming the URL, not running on into a longer number; the latest
   such report wins.
2. Otherwise the member whose recorded `branch` is the PR's head branch,
   from `gh pr view <url> --json headRefName`. The repo isn't compared.

With an owner it opens the plugin's `pr-member` pane, `placement =
"popup"`, passing `LOOPHERD_PR_MEMBER` and `LOOPHERD_PR_URL` through
`herdr plugin pane open --env`. That pane runs `loopherd pr --popup`,
which prints the member, herd, live status, template, review round (its
`done` reports this run, as `stats` counts rounds) and last five reports,
then waits in raw mode for q or Escape. Without an owner, or when GitHub
can't be asked, or when herdr refuses the popup (another modal open), it
opens the PR with `xdg-open`, or `open` on macOS, as herdr would have.

The card's live test (Ctrl-click a member's PR link in `scripts/herdr-dev`
with the plugin linked) is tests against the herdr fake and the built
binary with stubbed `gh`, `herdr` and `xdg-open`, plus an isolated `herdr
plugin link` of the manifest: linking the plugin into the dev server
registers it in the human's live herdr (D62).

LH-227 settled it.

## Why

A plugin action's output goes only to herdr's plugin log, so a popup pane
is the one place the human sees the answer. Reports are checked before
GitHub because members report their PR links, which costs no network call
and works off GitHub's head-branch name; the branch match catches a member
that opened its PR without reporting it yet. Falling back to the browser
keeps the handler from swallowing clicks it has nothing to say about.
