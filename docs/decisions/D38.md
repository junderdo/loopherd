# D38

## Decision

`loopherd setup` asks for `config.toml`'s machine-wide settings in two
groups: the lead defaults (D31's six switches, same wording and defaults
as `scripts/install` asked them), then the handoff values,
`context_window`, `default_context_limit` and `[shepherd] context_limit`.
Each context question says in one line what the value does and shows the
current effective value; Enter keeps it and writes nothing. A limit over
80% of the window is asked again, naming the cap, instead of being written
and capped silently. A group is asked only while `config.toml` leaves it
unset (the context group while none of its three keys is set); `--again`
asks both. `--lead-defaults <switches|none>` and `--context
window=<n>,limit=<n>,shepherd=<n>` (any subset) set values without asking;
either flag alone, with no value, asks just that group. Naming either flag
handles only the groups named.

Setup reads answers from `/dev/tty`, so it works under `curl … | sh`. With
no terminal it asks nothing, changes only what flags give, and prints one
line naming the flags for each group still unset. End of input counts as
Enter for every question left.

`loopherd config get|set|unset <key>` reads and writes the three context
keys through `toml_edit`, keeping comments and layout, writing through a
symlink, and refusing, changing nothing, an unknown key or a value under
10000. `get` exits 1 for an unset key.

`scripts/install` runs `loopherd setup` last, passing `--lead-defaults` and
`--context` through; `--no-extras`, `--remove`, or another extra named
alone skips it. A plain install whose setup fails warns and still succeeds;
one given a flag fails. It still checks a `--lead-defaults` list before
building, so a typo installs nothing.

The tool hook denies `loopherd config set`, `config unset`, `loopherd
setup` (not its `--help`) and `scripts/install --context` in a lead's pane
whatever its switches, as it does `lead-defaults --set` (D31): each could
raise the lead's own handoff limit or turn its switches on.

## Why

The one-line installer has no clone and no bash helpers, so the questions
move into the binary where both installers can call them, and the handoff
limits, which before needed a hand-edited `config.toml`, get the same
questions and a command that writes them. Re-asking an over-cap limit
keeps the human's number from being silently lowered at runtime. Per-herd
values stay with `loopherd init` (LH-125).
