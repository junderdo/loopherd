# D173

Builds D157's init re-run (LH-566).

## Decision

`loopherd init` in a repo whose herd exists re-asks that herd's settings
in place.

- **Keys are edited as keys.** `max`, `context_limit` and `merge_guard`
  change through toml_edit, keeping the file's comments and layout, and
  are asked whenever their table exists. A missing `[queue] max` or
  `[template.issue]` skips its question with a line naming where to edit.
- **Text settings are re-rendered.** Checks, gh account and default branch
  live in prose and commands, so init renders the herd as an earlier init
  would have from what the herd file records, renders it again with the
  new value, and carries each changed run of lines into the herd's files.
  A run is carried only where it appears in the file as often as in the
  rendering; otherwise the setting is "not init's own" and is skipped with
  one line, never guessed at.
- **"Init's own" is probed before asking.** The same carry with a probe
  value decides whether the question is asked at all. Checks also need
  every checklist item to be a bare `` `cmd` ``.
- **Adding a lead** appends init's `[lead]` table to the herd file and
  writes the lead prompt, prompt first, and is skipped when a prompt file
  already sits at the herd's lead prompt path.
- **Refused on a re-run:** `--tracker`, `--repo`, `--no-github` and
  `--with` (what makes a new herd), `--no-lead` on a herd with a lead, and
  a herd file `loopherd herds` calls invalid, which is fixed first.
- Each changed answer shows its diff and asks `Apply? [Y/n]`; without a
  terminal, a flag's change is applied and shown. The migration offers
  that follow are `loopherd herd upgrade`'s own.

## Why

A tailored herd is the common case (D157), so a re-run that re-wrote whole
files would undo the human's edits. Keys have a structural home; prose
doesn't, and loopherd never kept the text it first wrote, so re-rendering
is the only way to know which lines a setting owns. Probing before asking
keeps a question from being asked whose answer couldn't be applied. An
invalid herd can't pass the checks every write makes, so refusing it up
front beats refusing each answer.
