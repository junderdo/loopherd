# D160

## Decision

Amends D157's first migrations (LH-563, the human's call 2026-11-24).
`merged-repo` is skip and tell only: a `[template.issue] merged` without
`--repo` is always the herd's own value. Upgrade prints the `--repo` form
and where it belongs, writes nothing, and asks "Stop offering this?". It
never rewrites the docs/examples form. D157's rule that a hand-written
value is never edited stands unamended.

## Why

Every init ever released (v0.1.0 to v0.2.0) already wrote `merged` with
`--repo`, so no earlier init wrote anything to replace on an exact match.
The `--repo`-less checks in use were copied by hand from `docs/examples`;
the human fixes loopherd-cards' own by hand.
