# D9

## Decision

Slice 3: a herd file (`<herd>.toml`, D7) holds `repo`, an optional `workspace`
label (default: current workspace; an unknown label is an error), optional
`args`, and `[template.<t>]` entries with `params`, a `name` pattern (default
`{template}-{params}`), an optional `branch` pattern (unset: no worktree) or
instead a `worktree` pattern (`{param}`, `{herd}`, `{name}`) for a worktree at
that slug detached at origin's default branch, with no local branch and an
empty `{branch}` (LH-24), `prompt` or `prompt_file`, and `args`. `loopherd add
<herd> <template> <params…> [--dry-run] [-- args]` takes positional params and
spawns through spawn's code path; args go herd, then template, then CLI; the
ledger records `herd` and `template`. Placeholders are `{param}` plus the
built-ins `{name}` `{herd}` `{branch}` `{worktree}` `{pane}`, with `{{`/`}}`
escapes; spawn prompts get the built-ins. Unknown placeholders fail before
anything is created. loopherd stays free of GitHub knowledge: a PR template
uses `worktree` and its prompt runs `gh pr checkout --detach`, which works
even when the PR's branch is checked out elsewhere. `loopherd herds` lists and
validates herd files. Built as LH-14, LH-20, LH-21, LH-24.

## Why

Matches how workspaces are already used (by domain: `milk lab`, `my-app`), and
several herds can share one. Members are tracked by name and session, so they
may move. Grilled in LH-6, with LH-14.
