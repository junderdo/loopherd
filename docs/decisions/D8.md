# D8

## Decision

Revive (slice 2) is a manual, repeatable `loopherd revive [--dry-run]
[--name]` over ledger entries only. It waits for herdr's own resume to settle,
then for each entry that isn't retired and whose cwd and workspace still
exist: a live agent with its session ID is `alive`; otherwise it reuses a
matching shell pane or opens a tab named for the agent and runs `claude
--resume <session> <claude_args>`. It never answers dialogs, re-sends prompts
(except a lead's re-arm prompt, D17), replaces a name held by another session,
or recreates workspaces. The ledger gains `claude_args`, `workspace_label`,
and `retired`; `loopherd retire <name>` only marks an entry finished. Built as
LH-17 (retire) then LH-18 (revive).

## Why

herdr already resumes agents it started but drops their args, and closed tabs
aren't resumed at all (LH-10). Session ID is the only handle that survives
everything. Retire stops merged agents being resurrected. Grilled in LH-16.
