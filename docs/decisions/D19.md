# D19

## Decision

The shepherd's and lead's guide ships with the binary. `loopherd --skill`
prints one SKILL.md, frontmatter (`name: loopherd`, a description that
triggers on shepherding or leading a loopherd herd or the user mentioning
loopherd, not for workers) plus Shepherd and Lead sections. It is embedded
with `include_str!` from `skills/loopherd/SKILL.md`. `loopherd install-hook`
writes it to `<skills dir>/loopherd/SKILL.md`, overwriting each run, and
`--remove` deletes it (and its directory, if that leaves it empty). The skills
dir is `--skills-dir`, else `skills/` beside the settings file, so
`~/.claude/skills` by default and a temp dir whenever `--settings` names one.

**Split.** The skill holds only what's true for any herd: the roles, watch
(what it reads, locks, exit 2, re-arm, the line table), `reports` vs `reports
--all`, question reports, the six switches and the hook, the lead's heartbeat
and `merged`/`claimable` wakes, revive after restart, feed/retire/status,
talking to members, `blocked` being the human's (D10), and a task's life
(feed, watch, verify, after-merge). A project's tracker and its commands, its
install and checks, its GitHub account and merge line stay in that project:
here, [agents/shepherd.md](../agents/shepherd.md) is the `loopherd-cards`
runbook, and a lead's project facts stay in its herd's prompt file. Revive's
re-arm prompt and the example lead prompt name the skill's Lead section, not
a path. A test fails when a line kind `watch` prints is missing from the
skill's line table; another fails if the skill names this repo, Trello or
the GitHub account. This replaces D17's pointer to `agents/shepherd.md` as
the lead's playbook.

## Why

The lead prompt and revive's prompt pointed at `docs/agents/shepherd.md` by
relative path, which doesn't exist in another repo's herd (e.g. a
`zagops-prs` lead). Shipping the guide with the binary keeps it in step with
the loopherd that runs, follows herdr's `herdr --skill` precedent, and the
install makes Claude discover it unprompted. Grilled with the human
2026-11-03 (LH-89).
