# D132

## Decision

loopherd lists each member's running subagents (LH-381), recorded through
Claude's `SubagentStart` and `SubagentStop` hooks rather than read from the
liveness of transcript files.

- **Recording.** `loopherd subagent-hook`, installed on both events,
  appends a `subagent-start` or `subagent-stop` entry to the member's
  mailbox with the agent id, its type, the member's session and the time.
  Neither entry wakes a watch, shows in `reports` without `--all`, or
  counts as a sign of life against a `gone`. Inputs with an empty
  `agent_type` (Claude's internal agents) are skipped.
- **Description.** Neither hook input carries the Agent tool's
  `description`. Claude writes it to
  `<session>/subagents/agent-<id>.meta.json` beside the session's
  transcript, but only after `SubagentStart` has run (checked against
  Claude Code 2.1.330). The start entry records that path; `view` and
  `status` read the description from it, and a stop entry carries it.
- **Running.** A subagent runs from its start until its stop. Stops that
  never arrive are covered by dropping every running subagent at a
  `start` of the member's Claude or at a `stop` with no subagent in the
  background, and any started in another session than the ledger's
  (after `/clear`, or a nested Claude in the pane).
- **Showing.** `view` lists them as dim rows under their member,
  `↳ <type>  <description>  <age>`, which selection skips;
  `status --json` gives every member a `subagents` list of `id`, `type`,
  `description` and `started`.
- **Optional.** `doctor` warns, not fails, when either hook is missing,
  since `watch` doesn't need them.

## Why

A lead's reviewers and a worker's helpers were visible only at a stop,
through the Stop hook's coarse `background_tasks` counts. The hooks are
documented and fire at the moment a subagent starts and stops, where
transcript mtimes lean on an undocumented layout and guess at liveness.
The description still comes from that layout, so a missing `meta.json`
leaves only the row's description blank.
