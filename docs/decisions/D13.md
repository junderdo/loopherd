# D13

## Decision

Slice 4b is `loopherd view [--all] [--strays]` (LH-43), a ratatui TUI over
D12's core: it polls the same read as `status` every 2s and renders its
sections, rows and strays line, adding only a selection marker and a `for 3m`
column. That time is shown only for status changes the TUI saw while open,
never persisted; a poll that couldn't read herdr's agents changes no times.
Keys: `q`, `s` strays, `a` all, arrows/`j`/`k`, Enter focuses the selected
live member's or listed stray's pane with `herdr agent focus <pane>`, the only
herdr call besides reads, and like any herdr focus it marks the agent seen, so
a `done` agent may read `idle` next poll; on a gone member it says to revive.
Events (LH-44) replace polling later.

## Why

Grilled with the human 2026-11-01 on LH-43.
