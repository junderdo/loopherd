# D52

## Decision

When no live agent carries a retired entry's name and its recorded pane runs
an agent, that agent is the entry's own when its session matches the
entry's, another's when its session is another ledger entry's or it has a
name or a session that differs from the entry's, and unidentified
otherwise: no name, and a session missing on either side. `retire --close`
keeps an unidentified agent's tab, and `herd remove` and `release` refuse
it, naming the command that closes the tab and, for an agent that isn't
the entry's, the `herdr agent rename` that names it and so unblocks them.

## Why

herdr 0.9.5 shows a Claude with no name and no session when the Claude
doesn't run herdr's integration hook, and with no name after a server
restart (see `research/herdr.md`). Counting such an agent as another's
let `herd remove` drop a member's entry and files while its Claude still
ran. Only a different name or session proves the agent isn't the member's.
