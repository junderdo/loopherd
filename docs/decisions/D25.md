# D25

## Decision

A herd's queue can route each task to one of several templates. `[queue]`
takes `templates = ["<t>", …]` in place of `template = "<t>"`; then the first
word of each line `source` prints names the task's template, which must be in
that list, and the rest of the line is that template's params. A name not in
the list is a bad line (D14's bad-line rules). A herd file with `template`
works as now; one with both is an error, reported by `feed`, `watch` and
`loopherd herds`.

- One `max` covers every template: it bounds the human's review load, which
  doesn't depend on a member's kind. Caps per template can come later.
- Reaping is unchanged: `done` and `merged` already run each member's own
  recorded template (D14, D17). A lead's `claimable` line names the member
  feed would spawn, whatever its template.
- `status --json` gives each member its `template` (the ledger already holds
  it); `status`'s text, `view` and `watch` are unchanged, and a template's
  `name` pattern (`research-{card}` beside `lh-{card}`) tells kinds apart.
- A template picks a Claude agent definition, model or effort through its
  existing `args` (`["--agent", "…", "--model", "sonnet"]`); no new template
  fields.
- Reviewers stay the lead's subagents, not members.

`loopherd-cards` gets a `wayfinding` template (the card workflow on
`--model sonnet`, its own prompt) for `wayfinding:research`, `domain` and
`prototype` cards once this ships; grilling stays the human's.

## Why

Every task in a herd ran as the one queue template, so a docs or research
card got the same prompt, model and effort as a feature (LH-101). `source`
already decides what's claimable, so it can say which template takes it.

Rejected:

- **A routing table in the herd file** (patterns to templates): more config,
  duplicating what `source` already does.
- **Reviewers as members**: a review would survive the lead's handoff (two
  were lost mid-run this week) and be visible, but reviews come from a
  worker's `done`, not the queue, so they need a second source or hand
  spawning, their own `done`/`merged`, a slot rule that can't deadlock
  behind `max`, and every round relayed through the lead. Not worth it yet.
- **`agent`, `model`, `effort` template fields**: they duplicate `claude`'s
  flags, which `args` already passes.
