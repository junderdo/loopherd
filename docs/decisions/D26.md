# D26

## Decision

loopherd fits the human's existing Claude setup rather than replacing it: its
own agent types and the skills it suggests are optional extras that
`scripts/install` offers, never requirements.

**Agent types.** loopherd ships its own subagent definitions, written for
herd work, under `agents/` in the repo: `builder`, `reviewer`, `researcher`
and `scout`. `scripts/install --with-agents` copies them into
`~/.claude/agents/` and records each installed file's hash in
`$XDG_STATE_HOME/loopherd/`. On each run, per file:

- identical to loopherd's: skip;
- unchanged since loopherd installed it: update;
- edited since, or the human's own: ask whether to keep theirs, overwrite it
  after a backup, or install loopherd's as `loopherd-<name>`.

Nothing is overwritten without asking. They are subagent types that leads
and workers launch, used by role: a prompt asks for `reviewer` (the human's
or loopherd's), else `loopherd-reviewer`, else a general-purpose subagent.
Members don't run as them; a template can still choose `--agent` through its
`args` (D25).

**Skills.** `scripts/install --with-skills` installs the
`mattpocock-skills@claude-plugins-official` plugin, after listing skills in
`~/.claude/skills` with the same names as the plugin's (both load, since the
plugin's are prefixed).

**Asking.** Each extra is its own question, default no, and the installer
lists the overlaps it found before asking. `--no-extras`, or a run without a
terminal, installs neither. The loopherd skill stays where D19 put it.
D27 settles the flags: naming one extra installs just that one and asks
nothing about the other.

## Why

The human wants loopherd usable with anyone's workflow, not only its
author's, and not overly opinionated, while setup still offers the author's
defaults (LH-106). The author's own agent definitions derive from Leaven,
whose licence forbids sharing changed copies, so loopherd's are written fresh.
Plain files in `~/.claude/agents/` are ones the human owns and edits, which
is how agent definitions get used.

Rejected:

- **A loopherd Claude plugin for the agent types**: no file collisions and a
  clean uninstall, but its files sit in Claude's plugin cache, overwritten on
  update and awkward to edit, and it adds a marketplace, `plugin.json` and
  prefixed names. The hash rules handle collisions without it.
- **Shipping the author's Leaven-derived definitions**: the licence forbids
  sharing them.
- **Requiring the extras**: loopherd would then dictate the human's agents
  and skills.
