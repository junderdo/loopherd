# D40

## Decision

loopherd ships as GitHub Releases, installed by a one-liner:
`curl -fsSL https://github.com/junderdo/loopherd/releases/latest/download/install.sh | sh`.

- A pushed `v*` tag runs `.github/workflows/release.yml`: it fails unless the
  tag is `v` plus `Cargo.toml`'s version, runs the gate, builds x86_64 and
  aarch64 Linux (static musl, native runners) and x86_64 and aarch64 macOS,
  and publishes `loopherd-<target>.tar.gz` per target, `SHA256SUMS`, and
  `install.sh` with the release's tag stamped into its `release_tag=` line.
- `scripts/install.sh` is POSIX sh. It needs only `curl` or `wget`, `tar`,
  and `sha256sum` or `shasum`, refuses on a checksum mismatch before
  touching anything, installs through a temp file and rename, then runs
  `loopherd install-hook` and `loopherd setup` (D39) with stdin from
  `/dev/null`, so neither eats the piped script. `LOOPHERD_VERSION` pins a
  release, else the stamped tag, else latest; `LOOPHERD_RELEASE_BASE`
  replaces the releases URL, which is how the tests serve a fake release
  over `file://`. Agent types and the skills plugin stay in `scripts/install`.
- Versioning is SemVer from 0.1.0, with the below-1.0 rules and the 1.0 bar
  in `docs/releasing.md`. A release is a PR bumping `Cargo.toml`, then a tag
  on its merge commit; notes are GitHub's generated notes, no changelog.
- `build.rs` sets the version clap prints: bare for a clean build at the
  `v<version>` tag or one with no git, else `<version> (<short commit>)`
  with `-dirty` for uncommitted tracked changes.

## Why

The human wants an install that needs no clone and no Rust toolchain,
fronted by junderdo.dev. GitHub's `releases/latest/download/` URL makes the
one-liner stable across versions without a server of our own. Native ARM
runners and musl-tools build static Linux binaries without `cross` or
Docker. Stamping the tag into the release's `install.sh` keeps an old
release's installer installing what it shipped with. Telling a release
build from a clone build by the tag at HEAD needs no workflow-only switch,
so a clone checked out at the tag reports the same as the release.
