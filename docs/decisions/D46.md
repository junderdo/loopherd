# D46

## Decision

A first review runs the reviewer as its agent type defines it (Opus).
Later rounds of the same PR pass `model: sonnet` to the subagent. The
reviewer pipes gate output through `tail` or a grep for failures, and never
Reads a saved `tool-results/` file whole.

## Why

Reviewers cost about a third of one day's spend (~$55 of ~$172 on
2026-11-16). Later rounds only recheck the last findings against a small
diff, which Sonnet handles; the first review, which hunts bugs across the
whole change, keeps Opus. Reading saved tool output whole cost ~15k tokens
each time, eight times that day, for output whose tail holds the verdict.
