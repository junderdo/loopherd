# D47

## Decision

Shepherds and leads message members with `loopherd tell <name> <text>`
(or `--text-file`), not raw `herdr agent prompt`. `tell`, `prompt` and
`restart` read the pane first and refuse, sending nothing, while it shows a
subagent's view (prompt line `❯ Message @…`, or a picker whose selected `●`
isn't `main`); revive skips that lead's re-arm with a line saying why.
`tell` then waits up to 10s for the member to go `working` and says whether
it did, exiting 0 either way so a caller doesn't resend. loopherd never
switches the pane back itself.

## Why

On 2026-11-16 a relayed answer typed into a lead's pane reached its
reviewer subagent, because the human had clicked into that subagent's view
while watching; herdr still reported `agent_prompted`. Any glance at a
subagent can leave a pane there, and nothing switches it back. One check,
shared with restart's existing refusal, covers every loopherd path that types
into a member.
