# D125

Amends D98, D102 and D111.

## Decision

Follow-ups to the LH-307 stack (LH-355).

- **A lead's report is appended before its record and socket checks.** Its broker
  writes the report to the lead's mailbox first, then checks the lead's
  record and herdr socket only for a question's pane label, so a record or
  socket it can't use costs only the label, with a warning. The append's
  flock wait stays bounded at 30 seconds, inside the lead's 120-second
  wait. A report that times out tells the lead to check
  `loopherd reports --all <lead>` before reporting again, since the broker
  may have written it; a plain `reports` fails in its sandbox.
- **An old broker's fallback costs a question its label.** The lead
  writes the report itself and its warning says the pane gets no label.
  No legacy label request is sent.
- **On Linux a lead's settings name no path under `broker/`**, as D111
  already does for `handoffs/`. The `broker/*` glob covers the file tools,
  and Bash writes only what `allowWrite` names. Off Linux the literal
  denies stay.
- **Handoffs.** `set_aside` moves the other layout's older file first and
  only warns if it can't, in `restart`'s output, the shepherd's resume
  context or the Stop hook's stderr, so it can't fail a restart after
  `/clear`. The
  Stop hook's ask makes `handoffs/<name>/` before naming a path in it.
  `loopherd handoff` refuses empty or whitespace-only stdin rather than
  replace a handoff with it.
- **Upgrading a running lead** to a release with D111 is, in order:
  `loopherd broker-restart <lead>` (unless its broker already moved onto
  the new binary, D124), quit the lead's Claude, then
  `loopherd revive --name <lead>`.

## Why

- **The mailbox is the record.** A report the lead believes failed gets
  sent again, so the write must not hang on herdr, and a timeout must say
  it may have landed.
- **A legacy label request is surface for one upgrade.** A broker that
  can't read `report` is restarted by the shepherd anyway (D124 moves it
  by itself), so naming the lost label is enough.
- **A named path that later goes missing gets the Linux sandbox's empty
  placeholder** (D111). For `broker/` the placeholder isn't read as a
  handoff, but nothing needs the names: the glob and `allowWrite` already
  cover both tools.
- **Revived first, a lead's report fallback hits a read-only `reports/`.**
  Its new sandbox drops `reports/` from `allowWrite`, so its broker must
  already read `report`.
- **The live sandboxed-lead test checks the restart.** Its lead's
  worktree carries Stop and SessionStart hooks on the test's state dir, so
  the `restart --self` its probe arms restarts it once its turn ends; the
  test then waits for `prev.md` and a new session rather than reading
  `handoff.md`, which that restart moves.
