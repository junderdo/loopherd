# D161

## Decision

loopherd's user docs ship inside the binary as the loopherd skill's
reference files (LH-555).

- **Six references**, each embedded with `include_str!` from the repo file
  it's edited in: `tour.md` (docs/tour.md), `setup.md` (docs/setup.md),
  `install.md` (docs/install.md), `glossary.md` (CONTEXT.md),
  `herd-file.md` (docs/herd-file.md, an annotated general herd file and
  lead prompt) and `runbook.md` (docs/runbook.md, what a project's
  shepherd runbook holds). docs/ stays the one place they're edited.
- **Links are rewritten as embedded.** A relative link to another shipped
  doc points at its reference file, anchor kept; one to docs/examples/
  points at `herd-file.md`; one to any other repo file (decisions,
  research, README) becomes its plain label. A test checks every link in
  every reference resolves within the references dir.
- **`install-hook` writes them** to `references/` beside SKILL.md on every
  run, in every layout, replacing stale ones and pruning entries it no
  longer ships (dotfiles excepted: a concurrent install's temp files). A
  symlinked `references/` is replaced, not written through. Removing the
  skill removes `references/`.
- **`loopherd docs [<topic>]`** prints a reference, or lists the topics
  with when to read each, for a shepherd without the installed skill.
- **`doctor` warns** when the installed references are missing, differ or
  include unshipped files, naming `install-hook` as the fix.
- **`init` writes a `docs/agents/shepherd.md` stub** when missing, pointing
  at `loopherd docs runbook`; `init --diff` covers it.
- Out: docs/decisions/ and docs/research/ (loopherd's own history), and
  docs in the release tarball.

## Why

Outside this repo a shepherd had only `loopherd --skill`. The release
archive carries no docs, so the glossary, command tour, setup guide and
herd-file examples existed only in this checkout. Claude reads a skill's
reference files on demand, so SKILL.md stays short and the docs load only
when needed; embedding keeps them matched to the installed binary and
readable offline.
