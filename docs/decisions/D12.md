# D12

## Decision

Slice 4a is `loopherd status [--all] [--strays] [--json]` (LH-42), a read-only
CLI over a no-I/O core (`herd_view`) that the TUI (LH-43) reuses. Members are
ledger entries, herd entries under their herd and plain spawns under
`ungrouped`. An entry's live agent is found by retire `--close`'s rules (name,
then recorded pane + the entry's own session; shared in `matching`). Status is
herdr's `agent_status`, sorted blocked, done, idle, working, unknown, gone;
`gone` is a non-retired entry with no live agent, greyed on a tty with a
`loopherd revive` hint. Retired entries, and herds with only retired entries,
show only with `--all`, where such a herd's header reads `<herd> (retired
only)`; gone members always show, so a herd whose members are all gone still
appears. Live agents matching no entry are **strays**: always counted, listed
(pane, cwd, terminal title) with `--strays`. Order: herds by name,
`ungrouped`, `retired`, strays. Columns: name, status, branch (or `detached`),
worktree basename, tab/pane; an entry with no worktree shows `-` for both,
never the repo's branch, and the branch lookup ignores
`GIT_DIR`/`GIT_WORK_TREE`/`GIT_INDEX_FILE` and skips hidden entries; no
time-in-status (herdr has no timestamps). One `agent list` read; unreachable
herdr prints the ledger as `unknown`, warns, exits 2; a malformed `agent list`
reply prints the same, with an error naming herdr's output, and exits 3
(LH-46). `--json` is `{herdr_reachable, herds: [{name, members}], ungrouped,
retired?, strays: {count, agents?}}`, members `{name, status, gone, branch,
worktree, pane, tab, lead}`, unstable.

## Why

The human needs one glance at what needs them. Strays show what's not herded
without adopting anything. Grilled with the human 2026-11-01 on LH-42.
